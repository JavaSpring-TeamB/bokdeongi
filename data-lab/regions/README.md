# 시·도/시군구 목록 (regions 시드, D-73)

주소 입력(PROF-02)과 지역 판정에 쓰는 `regions` 테이블 데이터를 만든다.

## 원본

행정표준코드관리시스템(code.go.kr) → 법정동코드 → **법정동코드 전체자료** (zip 안의 txt, 탭 구분, CP949).
2026-07-01 행정구역 개편(전남광주통합특별시, 인천 제물포·영종·서해·검단구)이 반영된 파일이어야 한다.
원본 txt(약 2.4MB)는 레포에 올리지 않는다. 필요할 때 다시 내려받는다.

## 실행

```bash
python data-lab/regions/build_regions.py "법정동코드 전체자료.txt" -o regions.sql
python -m unittest discover -s data-lab/regions
```

## 규칙

| 남김 | 버림 |
| --- | --- |
| 폐지여부 = 존재인 시·도(코드 2자리), 시군구(코드 5자리) | 폐지된 코드, 읍면동·리 |
| 세종특별자치시는 시군구가 없어 `36110` 한 줄(sigungu_name NULL) | 일반구(수원시 장안구 등). 혜택 기관이 시 단위라 시만 고른다 |

- 2026-10 자료 기준 245줄 (시·도 16 + 시군구 229)
- 순서(sort_order)는 서울 → 광역시 → 세종 → 도 → 제주, 시·도 안에서는 코드순
- 옛 자료(전남광주통합특별시 없음)나 순서표에 없는 시·도가 나오면 오류로 멈춘다
- 생성된 SQL은 지우고 다시 넣는 방식이라 여러 번 실행해도 같다
