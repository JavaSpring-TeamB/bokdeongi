# data-lab

데이터·규칙 담당과 AI 튜닝 담당의 실험 공간.

| 작업 | 내용 |
| --- | --- |
| API 실측 | 공공서비스(혜택) API 3종 호출, 지원조건 코드 매핑, 신청기한 형식 분포 → [`api_survey/`](api_survey/README.md) |
| 정답셋 | 표본 추출 기준, 라벨링 가이드, 라벨 파일 |
| 정확도 측정 | 기준 구조화·판정·날짜·금액·해시태그·OCR 정확도 |

- 원본 응답·대용량 파일은 `data/raw/`에 두고 커밋하지 않는다 (`.gitignore`)
- 인증키는 `.env`에서 읽는다
- 노트북에는 실행 결과 중 개인정보가 없는지 확인 후 커밋한다
